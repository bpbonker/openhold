# Changelog

All notable changes to Openhold are listed here. Versions follow [Semantic Versioning](https://semver.org/).

## 1.0.0-beta.1 (unreleased)

The first public beta, for testing ahead of 1.0.

- **Files and versions:** check-out / check-in / undo, atomic changesets, history, Get Latest / Get Version, Uses and Where
  Used, trash, unique CAD file names, property editing across many files.
- **CAD:** Inventor add-in (2025+), AutoCAD / AutoCAD Mechanical / AutoCAD Electrical plugin with project sets,
  Save to Openhold naming in Inventor.
- **Release control:** categories, lifecycles, approvals, explicit Revise, stamped PDFs with QR codes.
- **Numbering:** a part-by-part scheme builder, naming rules from folders and parent assemblies, reservations.
- **Catalogue and ERP:** item master with classes and attributes, approved manufacturers, CSV and simPRO
  connectors.
- **Multi-site:** authority, site and backup server roles; content-addressed chunk replication between peers.
- **Security:** Windows sign-in, Openhold accounts with two-factor codes, groups and privileges, folder
  permissions, append-only audit, encrypted backups.
- **Installation:** a Docker image and Compose file for the server, with the first administrator created on the
  first start; guides for Docker, Ubuntu and Debian, Windows Server and client PCs; step-by-step how-to guides.
- **Licence:** open source under the Apache License 2.0.
- **Name:** pilot installations under the working name Strata keep their client settings, workspaces and
  encrypted backups.
