# How-to guides

Short, task-focused guides. Each one starts with what you'll achieve, then gives the steps. For the full picture,
see the [user guide](../user-guide.md), the [administrator guide](../administration.md) and the
[installation guides](../install/README.md).

## Administrators

Getting started, in this order:

| Guide | What you'll do |
|---|---|
| [Set up your vault](set-up-your-vault.md) | Folders, categories, lifecycles and revisions for a new vault |
| [Add people](add-people.md) | Accounts, sign-in, groups, folder permissions, two-factor, disabling someone |
| [Build a numbering scheme](numbering-scheme.md) | Build a scheme part by part, naming rules, catalogue numbers |
| [Back up and restore](back-up-and-restore.md) | Nightly backups, checking them, and a test restore |

Then, as you need them:

| Guide | What you'll do |
|---|---|
| [Import existing files](import-existing-files.md) | Bring existing project folders in with OpenholdImport, dry run first |
| [Publish PDFs on release](publish-pdfs.md) | Set up the job worker that stamps released drawings with a QR code |
| [Connect an ERP](connect-an-erp.md) | Send released catalogue items to a CSV file or simPRO |
| [Add an office](add-an-office.md) | A site server or a backup server, with a streaming replica |
| [Upgrade Openhold](upgrade.md) | Server, Openhold Explorer, add-ins and job worker |
