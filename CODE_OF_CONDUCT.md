# Code of Conduct

This code applies wherever the Openhold project meets: issues, pull requests, discussions and any other project
space. Everyone taking part is expected to follow it.

## Expected

- Be respectful and assume good intent; people's first language and experience vary.
- Give and take feedback on the work, not the person.
- Help newcomers find their way.
- Keep other organisations' data private: never post real drawings, part data, credentials or customer details.

## Not accepted

- Harassment, insults, or discriminatory language or imagery.
- Personal or political attacks, trolling, or sustained disruption.
- Publishing anyone's private information without their permission.
- Any conduct that would reasonably be considered inappropriate in a professional setting.

## Enforcement

Maintainers may remove comments, commits, code and issues that break this code, and may temporarily or
permanently ban a contributor. Report a problem privately to the maintainers through the contact details on the
project owner's GitHub profile; reports are handled confidentially.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
